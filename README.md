# Documentation/Blog FPGA, DSP and SDR related information

## Create python enviroment

### VSCode enviroment

- Type **Ctrl+Shift+P** and select **create python enviroment**.
- Select the python version to use.
- Activate the enviroment with **Ctrl+Shift+P** and select **Python: Select Interpreter**.
or from the terminal with `source .venv/bin/activate`.
- Install the required packages with `pip install -r requirements.txt`.

## Deploy to github pages

- `mkdocs gh-deploy`

## Documentation

### Block diagrams and images

- Excalidraw: https://excalidraw.com/ install the extension for vscode. This
    is a great tool for drawing diagrams. This is used for the block diagrams
    in the documentation. This is use to avoid using binary image files in the repo.
